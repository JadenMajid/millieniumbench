03 · Evaluation Protocol

How MillieniumBench Scores Progress

Evaluating AI on unsolved conjectures requires preventing hallucinated "proofs" while still measuring genuine mathematical capability. MillieniumBench pairs strict machine verification with four graded evaluation tiers.

Tier 1 · 25%

Formalization Foundations

Models formalize core definitions, spaces, and prerequisite theorems for each problem inside a pinned Mathlib4 environment with zero sorry placeholders.

Tier 2 · 35%

Barrier & Partial Milestones

Models independently reconstruct landmark partial results and obstruction barriers (e.g., Razborov–Rudich, Hardy’s critical-line theorem, Gross–Zagier, Beale–Kato–Majda).

Tier 3 · 20%

Adversarial Flaw Audit

Given 160 historical and synthetic flawed Millennium "proofs," systems must pinpoint the exact first invalid deduction—testing mathematical rigor against plausible-sounding errors.

Tier 4 · 20% + Prize Gate

Poincaré Control & Open Frontier

End-to-end reconstruction of Perelman’s solved Poincaré proof calibrates deep proof planning, while open-problem proof attempts pass Lean 4 kernel checks plus human referee audit.

Composite Score Formulation
S_MB = 0.25·T_form + 0.35·T_mile + 0.20·T_audit + 0.20·T_poincaré (plus +100 Prize Gate per verified open proof)
Zero-Axiom Rule: Custom axioms or sorry auto-fail kernel checks. Clean Sandbox: No web search or arXiv retrieval during evaluation runs. Reproducible Traces: Every leaderboard entry publishes full Lean proof logs.
04 · Open Source & Contributions

Run the Harness & Submit via GitHub

MillieniumBench is hosted openly on GitHub. Researchers, labs, and independent mathematicians can evaluate any LLM or formal prover locally and submit verified traces via Pull Request.

  • Pinned Lean 4.14.0 + Mathlib4 Docker image for deterministic replay
  • Automated GitHub Actions CI checks every PR submission against the Lean kernel
  • Open dataset of 160 formal subtasks and 160 annotated flawed proof manuscripts
  • MIT-licensed harness and CC-BY-4.0 benchmark metadata
Open GitHub Repository Download benchmark.json 
# 1. Install the MillieniumBench harness
pip install millieniumbench

# 2. Pull the pinned Lean 4.14 + Mathlib4 verification sandbox
millieniumbench setup --lean 4.14.0

# 3. Run evaluation across all 7 Clay Millennium Problems
millieniumbench eval \
  --model your-org/your-prover-v1 \
  --harness lean4-agent \
  --split all \
  --output submissions/your-org/your-prover-v1.json
# Fork & clone the MillieniumBench repository
git clone https://github.com/<your-user>/millieniumbench.git
cd millieniumbench

# Add your verified trace & summary JSON
cp results.json submissions/your-org/your-model.json

# Validate locally before opening a Pull Request
millieniumbench verify submissions/your-org/your-model.json

git checkout -b submit/your-model
git add submissions/your-org/your-model.json
